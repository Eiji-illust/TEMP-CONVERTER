# Temperature Converter

A simple web-base temperature converter that allows users to convert values between **Celsius**, **Fahrenheit**, and **Kelvin** using Javascript.

## Features
-  Convert temperaturesbetween Celsius, Fahrenheit, and Kelvin
-  User-friendly input and unit selection
-  Instant result display
-  Clean and minimal UI

## Build With
- HTML
- CSS
- Javascript (Vanilla JS)

## Getting Started

### How to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/EIji-illust/TEMP-CONVERTER.git
2. Open index.html in your browser
   No Additional setup or dependencies required.

##How it Works
1.  The user enters a temperature value.
2.  The user selects the original unit.
3.  The user chooses the target unit to convert to.
4.  Clicking Submit display the converter temperature.
